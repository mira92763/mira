# MIRA Web — версия 0.1

## Публикация на GitHub Pages
1. Создай репозиторий GitHub с названием `mira`.
2. Загрузи в корень репозитория файл `index.html`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main` и папку `/ (root)`, нажми Save.
6. Через несколько минут сайт появится по адресу `https://ТВОЙ-ЛОГИН.github.io/mira/`.

## Важно
Это фронтенд-прототип. Чаты, профиль и подарки работают локально в открытой странице; данные не синхронизируются между пользователями и не являются настоящими аккаунтами. GitHub Pages размещает статические файлы и сам по себе не запускает серверную часть. Для реальной регистрации, приватных чатов и синхронизации следующей версией подключим Supabase (Auth, Database, Realtime) и настроим правила доступа.

## Локальный запуск
Открой `index.html` в браузере.
